# Agents HTML Design System

This repo provides a design system to use for agent-generated HTML files to clarify and communicate over specs, plans, designs, and to make the planning process overall more enjoyable than just looking at pure text files like Markdown, which have a bit of design context but still lack the possibilities that HTML provides, like interactivity using proper UI components, graphs, diagrams, etc. 

It derives and picks up from the idea of Thariq, an employee of Anthropic who proposes and advocates for using HTML over Markdown in certain scenarios.

This is his original Blog Post on X/Twitter:
[Using Claude Code: The Unreasonable Effectiveness of HTML](https://x.com/trq212/status/2052809885763747935)

And here is the repository that goes alongside it. [html-effectiveness (GitHub)](https://github.com/ThariqS/html-effectiveness)
